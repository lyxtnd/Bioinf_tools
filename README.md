# Bioinf_tools

Программа разработана в рамках учебного задания по информатике и представляет собой библиотеку на языке Python для чтения биологических файлов. 

Программа реализована без использования специализированных библиотек для работы с последовательностями (таких как Biopython). При написании использовались только стандартная библиотека Python, а также пакеты для статистической обработки и визуализации данных.

Программа поддерживает работу с четырьмя форматами биологических данных: FASTA, FASTQ, SAM и VCF. 
Все модули чтения реализованы с применением генераторов, что позволяет эффективно работать с файлами большого объёма без избыточной нагрузки на оперативную память.

## Что умеет программа

- FASTA — читает последовательности, определяет, белок это или нуклеотид, считает количество записей и среднюю длину.
- FASTQ — тоже читает записи, но ещё и строит графики по качеству (per base sequence quality, content, length distribution) — примерно как FastQC.
- SAM — разбирает заголовок и группы (@PG, @RG и т.д.), считает выравнивания, строит статистику по хромосомам через pandas, умеет искать выравнивания в заданном геномном интервале (аналог bedtools intersect).
- VCF — разбирает заголовок, считает варианты, строит статистику по регионам через pandas, ищет варианты в заданном интервале.
- Общая основа — абстрактные классы Reader и GenomicDataReader, от которых наследуются все ридеры. Так код получается единообразным.

## Как установить

1. Склонируйте репозиторий:
   git clone https://github.com/lyxtnd/Bioinf_tools.git
   cd Bioinf_tools

2. Создайте виртуальное окружение:
   python -m venv venv
   source venv/bin/activate        # Linux/Mac
   # или
   venv\Scripts\activate           # Windows

3. Поставьте зависимости:
   pip install pandas matplotlib seaborn plotly sphinx sphinx-rtd-theme

## Как запустить демонстрацию

В репозитории уже лежат готовые демо-скрипты и тестовые файлы для каждого формата. 
Запускать нужно из корня проекта:

| Формат | Что запустить | Какие данные используются |
|---|---|---|
| FASTA | python FASTA/fasta_test.py | FASTA/example_1.fasta, FASTA/example_2.fasta |
| FASTQ | python FASTQ/fastq_test.py | FASTQ/ |
| SAM | python SAM/sam_test.py | SAM/example_1.sam |
| VCF | python VCF/vcf_test.py | VCF/example_1.vcf |

> Если у вас sam_test.py лежит прямо в корне (а не в папке SAM/), запускайте просто python sam_test.py.

Пример того, что выводит демо по FASTA:

=================================================================
Читаем файл: FASTA/example_1.fasta
=================================================================
Заголовок: seq1 example nucleotide
Длина: 20
Тип: nucleotide
...
Средняя длина: 10.67

## Документация

Документацию мы собрали через Sphinx (с расширениями autodoc, napoleon, viewcode и темой sphinx_rtd_theme). 
Готовые HTML-страницы уже лежат в репозитории:

docs/_build/html/index.html

Просто откройте этот файл в браузере — там описаны все модули, классы и функции.


## Что где лежит

Bioinf_tools/
├── abstract_readers.py    # базовые абстрактные классы (Reader, GenomicDataReader)
├── fasta.py               # ридер FASTA + класс Seq
├── FASTQ.py               # ридер FASTQ + графики качества
├── sam.py                 # ридер SAM
├── vcf.py                 # ридер VCF
├── FASTA/                 # демо-скрипт и примеры для FASTA
├── FASTQ/                 # демо-скрипт и примеры для FASTQ
├── SAM/                   # демо-скрипт и примеры для SAM
├── VCF/                   # демо-скрипт и примеры для VCF
├── docs/                  # Sphinx-документация (HTML в docs/_build/html)
└── README.md

## Что нужно для работы

- Python 3.10 или новее
- pandas, matplotlib, seaborn, plotly — для статистики и графиков
- sphinx, sphinx-rtd-theme — только если хотите пересобирать документацию
